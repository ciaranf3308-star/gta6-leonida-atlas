The companion rebuild — one database for map, journal, progress and Ask

v0.32.0 · 26 November 2026 · Released

The fundamental product reset: Map, Collections, Progress and Ask are now four views of one unified gameplay database, so marking a card collected updates the set, the map marker, Progress and Ask, and survives a restart and a backup restore. Gang operations, the card album, on-demand building research and a structured Ask arrive with it. Live was v0.31.5 until this release.

What is included

  • One unified gameplay database (the reset, briefed 2026-11-26): a GameLocation carries its opportunities and collectible items, and every completion is one append-only log — collected, looted, discovered, explored — with manual in-game tallies kept separate as reconciliation entries, never summed with derived counts. Map, Collections, Progress and Ask are selectors over the same records, not four databases. The acceptance demos prove it on a real build: collect Vicki → journal 1/18, Starlet pin 'Vicki Collected', Progress 1/18, restart + export/wipe/restore with the original timestamp kept.
  • Collections journal + Progress dashboard: every set and item is trackable even with no map position — 480 card slots plus 117 extra game-text tiers, 614 rows in the journal. Progress is derived from the log only (1,325 required); the overall percentage correctly does not move for cards or exploration (per-category capping). Backup format v4 is a strict superset of v3; photos and research requests stay on the device and are never in a backup.
  • Ask Nylah is structured tools, not keyword patches: a bare set name works — 'Delight dancers' now returns all 5 Delights cards including Harley (the v0.31.5 gap, where 'Delights' as an area word dropped the Loot Map card, is closed). 'Find this card' calls a web-search-enabled model and returns a proposal with sources and confidence, never an auto-placed pin. Progressive hints run level by level behind a 'Bigger hint' button. Without a key, personal-progress questions refuse honestly ('I can't check that without your OpenAI key') instead of answering with a proximity verdict that can state the opposite of the truth.
  • Gang operations + likely areas: all 39 gang ops imported (37 area-known, 2 host-matched; Brooks Boatworks carries safe code 6823). Area-known records draw as dashed likely-area regions over their named area — 27 draw their own extent, 7 a county extent, 3 draw nothing — and a region never becomes a pin by zooming in. Ask answers gang ops by name and by kind with no key. The Port Gellhorn guides node and the catalogue town node were proven the same place, so Brooks draws the Port Gellhorn town rect with the other five ops.
  • Album + on-demand building research: the Album renders all 480 slots with front/back flip, rarity frames and collected/sold state (uncollected cards show name + silhouette only — no fake card faces, ever; no licensed artwork exists yet). Screenshot upload proposes completion updates for confirmation, nothing auto-applied. 'Research this building' is an explicit tap only, with a call counter, freshness display, tier gating and a Conflicts row; nothing AI-produced ever becomes a verified fact.
  • Honest gaps, carried openly: the keyed Ask steps need your OpenAI key on your phone (what's left in a set, 'have I found Vicki?', break-ins looted in Capri, places explored in Lummox, the whole hint ladder, a live research call, a live screenshot match) — the sandbox has no key, so those steps are tool-level verified and on-device owed. Only 7 of 17 region labels are visible at island zoom (the rest are suppressed rather than overlapped, and return exactly on zoom); one label line sits behind the filter chips at island zoom; and 'Show everything' does not clear a narrow filter (pre-existing — 'Clear filters' next to it works, fix queued after ship).
